# Unique React / Express Practical Set — 01 to 07

This set is a fresh implementation based on the practical concepts in the supplied practical document. The sample themes, names, layouts and source code have been replaced with original implementations.

## Projects
1. Practical_01 — Student Club Directory — Functional Components, JSX, reusable components
2. Practical_02 — Weekly Study Planner — Props, State Management, Event Handling
3. Practical_03 — Workshop Registration — React Forms, Controlled Components, Validation
4. Practical_04 — DayTrip City Guide — React Router SPA
5. Practical_05 — Learn & Gear Dashboard — Fetch API + Axios
6. Practical_06 — Campus Library API — Express routing, middleware, request handling
7. Practical_07 — Student Records REST API — GET/POST/PUT/DELETE for Postman

## General React setup
Open a practical folder in VS Code, then:
`npm install`
`npm run dev`

## General Express setup
Open the Express practical folder, then:
`npm install`
`npm start`

`node_modules` is intentionally NOT included so the ZIP stays small. Each project contains its source code and an `output.png` preview.
