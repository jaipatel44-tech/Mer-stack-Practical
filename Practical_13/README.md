# Practical 13: DocFlow Document Management System

Original implementation created for Jay. No code or screenshots copied from reference files.

MongoDB required. Start server (`npm install && npm start`) and client (`npm install && npm run dev`). Open http://localhost:5173. Upload PDF/JPG/PNG/TXT, search, download, archive/restore, delete. This is a local academic demo without authentication; do not expose to the public Internet.

For MongoDB projects create a local `.env` based on `.env.example`. Never commit credentials.
